## How I Approach Analytics

1. Validate the data and define the metrics before interpreting results.
2. Use SQL and Python to explore patterns and compare customer or business segments.
3. Communicate findings through dashboards and concise recommendations.
4. Document limitations clearly: observed patterns do not automatically prove causation.
