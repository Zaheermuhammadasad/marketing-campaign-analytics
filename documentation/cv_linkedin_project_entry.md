# CV and LinkedIn Project Entry

## CV

**Marketing Campaign & Customer Analytics | SQL, Python, Pandas, Plotly**

- Analysed a public marketing/customer dataset covering 2,240 customers and 29 source fields, including product spending, purchasing behaviour and campaign response.
- Built data-quality checks for missing income, duplicate identifiers and implausible birth years.
- Analysed campaign acceptance and latest campaign response; observed a 14.91% response rate in the sample.
- Examined 1,356,988 in recorded spend across six product groups and compared web, catalog and store purchase counts.
- Developed SQL queries, a reproducible Python/Pandas workflow, an interactive Plotly dashboard and documented marketing recommendations with explicit measurement limitations.

**GitHub:** https://github.com/Zaheermuhammadasad/marketing-campaign-analytics

## LinkedIn project description

Built an end-to-end marketing analytics portfolio project using a public customer/campaign dataset. Used SQL and Python/Pandas to validate data quality, analyse historical campaign acceptance, measure latest-campaign response, explore product spending and compare purchasing channels. Created an interactive Plotly dashboard and documented testable recommendations and limitations. The observed latest campaign response rate was 14.91% across 2,240 customers. This is descriptive performance, not causal lift.

Project repository: https://github.com/Zaheermuhammadasad/marketing-campaign-analytics

## Interview preparation note

Be prepared to explain how response rates are calculated, why customer-level purchase counts are not conversion rates, how missing and extreme income values are treated, and why the dataset cannot support ROAS or causal-lift claims.
