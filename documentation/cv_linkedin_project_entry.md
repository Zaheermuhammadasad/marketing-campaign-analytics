# CV and LinkedIn Project Entry

## CV

**Marketing Campaign & Customer Analytics | SQL, Python, Pandas, Plotly**

- Analysed a public customer marketing dataset covering 2,240 customers and 29 fields, including product spend, purchasing behaviour, profile attributes and campaign response.
- Built quality checks for missing income, duplicate IDs, and implausible birth-year records.
- Compared latest campaign response with five historical acceptance fields; the observed latest response rate was 14.91%.
- Analysed 1,356,988 in recorded spend across six categories, with wine and meat products largest.
- Developed SQL queries, a reproducible Pandas workflow, an interactive dashboard, and documented limitations around causal lift and ROI.

GitHub: https://github.com/Zaheermuhammadasad/marketing-campaign-analytics

## LinkedIn

Built an end-to-end marketing analytics project using SQL, Python/Pandas and Plotly. Analysed customer spending, product preferences, purchase-channel counts, data quality, historical campaign acceptance and latest campaign response. Created reproducible outputs, an interactive dashboard and testable recommendations with clear analytical limitations.

The sample contains 2,240 customers and a 14.91% latest-campaign response rate. This is descriptive, not causal lift: the source lacks advertising costs, impressions/clicks and randomized holdout data.

Project: https://github.com/Zaheermuhammadasad/marketing-campaign-analytics
