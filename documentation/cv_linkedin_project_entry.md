# CV and LinkedIn Project Entry

## CV

**Marketing Campaign & Customer Analytics | SQL, Python, Pandas, Plotly**

- Analysed a public marketing dataset covering 2,240 customers and 29 fields, including product spending, purchase behaviour, profile attributes, and campaign response.
- Built data-quality checks for missing income, duplicate IDs and implausible birth years.
- Compared latest campaign response with five historical acceptance flags; current response was 14.91% in the observed sample.
- Analysed 1,356,988 in recorded spend across six categories, with wine and meat products largest.
- Developed SQL queries, a reproducible Pandas workflow, an interactive dashboard, and documented limitations around causal lift and ROI.

GitHub: https://github.com/Zaheermuhammadasad/marketing-campaign-analytics

## LinkedIn

Built an end-to-end marketing analytics project using SQL, Python/Pandas and Plotly. Analysed customer spending, product preference, purchase-channel counts, data quality, historical campaign acceptance and latest campaign response. Created reproducible outputs, an interactive dashboard and testable recommendations with clear analytical limitations.

The sample contains 2,240 customers and a 14.91% current response rate. This is descriptive rather than causal: the data has no ad spend, clicks/impressions or randomized holdout.

Project: https://github.com/Zaheermuhammadasad/marketing-campaign-analytics
