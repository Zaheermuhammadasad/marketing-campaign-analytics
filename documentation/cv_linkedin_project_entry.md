# CV and LinkedIn Project Entry

## CV

**Marketing Campaign & Customer Analytics | SQL, Python, Pandas, Plotly**

- Analysed a public marketing dataset covering 2,240 customers and 29 fields, including customer attributes, product spending, channel counts and campaign response.
- Built data-quality checks for missing income, duplicate IDs and implausible birth-year records.
- Compared latest campaign response with five historical campaign acceptance fields; observed latest response was 14.91%.
- Analysed 1,356,988 in recorded spend across six product groups, led by wine and meat.
- Developed SQL analyses, a reproducible Pandas workflow, and an interactive dashboard while documenting causal-lift and ROI limitations.

GitHub: https://github.com/Zaheermuhammadasad/marketing-campaign-analytics

## LinkedIn

Built an end-to-end marketing analytics project using SQL, Python/Pandas and Plotly. Analysed customer spending, product preferences, purchase-channel counts, data quality, historical campaign acceptance and latest response. Created reproducible output tables, an interactive dashboard, and testable recommendations with clear limitations.

The sample contains 2,240 customers and a 14.91% latest-campaign response rate. This is descriptive, not causal lift; source data lacks ad costs, impressions/clicks and randomized holdout data.

Project: https://github.com/Zaheermuhammadasad/marketing-campaign-analytics
